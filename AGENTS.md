## Identidad compartida de Tinta

Antes de modificar una interfaz, lee `BRAND.md` y `DESIGN.md` de este repositorio.
Usa los SVG oficiales de `public/brand/`; no reconstruyas el logo con tipografía.
BRAND.md define la marca común; DESIGN.md conserva las convenciones de esta interfaz.
No migres el tema ni los componentes existentes como efecto secundario de sincronizar.
Para actualizar los recursos compartidos, usa `scripts/sync-brand.py` desde
`cuadra-landing`; las copias locales se verifican mediante `.brand-sync.json`.
